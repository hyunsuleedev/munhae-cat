## 실제 클릭으로 검증

1. 기본 독음을 수정하지 않고 채택 → 저장 버튼 활성화 → 저장 완료.
2. 然 뜻 후보 선택 → 錢塘 이동 → 然 복귀: 미저장 후보 유지.
3. 뜻 저장 → 용례 비교: 선택 어휘 강조, 시연 출처 표시.
4. 연결된 번역 편집 → 저장 → 새로고침: 수정한 번역과 어휘 저장 수 유지.
5. 원문에서 방향키 이동: 然 → 金陵, 연구 패널 동기화.
6. 앞뒤 문맥 펼치기 → 닫기: 저장된 실제 원문 표시.
