# 文解 — 책을 펼치는 시간

Three.js / WebGL로 만든 **독립 스플래시 시안**입니다. Electron 앱, 로그인, 프로젝트 데이터와 연결하지 않았습니다. 앱의 시작 동작과 의존성도 변경하지 않습니다.

## 실행

이 디렉터리에서 실행합니다. 별도의 `package-lock.json`을 사용합니다.

```sh
npm install
npm run dev
```

<http://127.0.0.1:4178/>에서 확인합니다.

```sh
npm run build
npm run preview
```

## 장면

- 짙은 녹색 천 표지, 한지 질감, 23겹의 종이 단면, 네 군데의 실 제본
- 표지가 열리고 세 장의 종이가 차례로 휘어지며 넘어가는 장면
- 3초부터 `文`의 4획과 `解`의 13획이 6.25초 동안 순서대로 써지는 총 10.75초의 시안
- 붓끝을 따라 나타나는 획, 젖은 먹의 농담과 반사, 종이 섬유를 따라 번지는 가장자리, 마지막 낙관
- 부드러운 조명과 그림자, 마우스 움직임에 반응하는 작은 시점 변화
- 고양이 없이 로컬 재질과 함께 포함된 붓글씨 벡터를 사용하며, 실행 중 외부 이미지·폰트를 다운로드하지 않음

책장 모양과 법선, 그림자용 깊이 재질에 같은 변형을 적용합니다. `book.ts`의 `leaf()`가 책장 변형을, `calligraphy.ts`가 획별 쓰기를 담당합니다. 붓글씨 마스크의 R 채널은 먹의 농도, G 채널은 젖은 정도를 저장합니다. 셰이더가 이 마스크 주변을 샘플링하여 시간이 지날수록 번지는 가장자리와 젖은 먹의 반사를 표현합니다. 물리 유체 시뮬레이션이 아닌 실시간 렌더링용 표현입니다.

종이에 쓰인 작은 한문은 이 시안을 위해 작성한 장식 문구이며 특정 고전 판본의 복제가 아닙니다.

## 확인 도구

하단에서 다시 재생, 일시정지, 시간 이동, 속도 변경을 할 수 있습니다. **붓글씨 확대**로 종이 위 글씨를 가까이 볼 수 있습니다. **전환 보기**는 시안 안의 가상 시작 화면으로 이동합니다. 실제 앱을 열거나 데이터를 변경하지 않습니다.

‘동작 줄이기’를 설정하면 정지 장면을 표시합니다. WebGL을 사용할 수 없으면 평면 표지를 표시하며, 탭이 숨겨져 있거나 재생이 끝나면 지속적인 렌더링을 멈춥니다. 실제 앱에 적용할 때는 준비 완료 신호와 전환을 연결해야 하며, 이 시안의 10.75초를 앱의 최소 대기 시간으로 사용하지 않습니다.

## 검증

`npm run build`로 TypeScript 검사와 독립 빌드를 실행합니다. 브라우저에서 책장 중간 장면, 재생/일시정지, 시간 이동, 속도 변경, 시작 화면 전환 및 복귀, 작은 화면, 동작 줄이기를 확인했습니다.

스크린샷은 저장소의 `output/playwright/munhae-splash-*.png`에 있습니다.
