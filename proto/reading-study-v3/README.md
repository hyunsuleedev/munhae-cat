# 글자별 구절 연구 데모

`index.html` 하나에 스타일, 데이터, 동작이 모두 들어 있습니다. 파일을 브라우저에서 열거나 아래 명령으로 실행할 수 있습니다.

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory proto/reading-study-v3
```

미리보기: http://127.0.0.1:8766/

- **A · 카드 정돈 / B · 행 맞춤**: 같은 훈음·뜻을 두 배치로 비교합니다.
- **글자 선택**: 오른쪽에서 뜻 후보와 독음을 확인·변경·저장합니다.
- **어휘 선택**: 묶음 밑줄 또는 Shift+클릭을 사용합니다.
- **기본 훈 / 어순 / 직해 대응**: 정보 층을 전환합니다.
- **예문**: 관서악부서 21자, 논어 19자, 대학 50자를 제공합니다.
- **키보드**: 방향키 이동, Shift+방향키 범위 선택, ⌘S / Ctrl+S 저장.

뜻풀이와 번역은 시연용입니다. 실제 사전의 인용·검증된 연구 결과가 아닙니다. 직해는 미리 작성한 별도 시연 데이터이며 뜻을 수정해도 자동 번역되지 않습니다. 대학 예문에는 직해 대응이 없습니다.

저장 대상은 이 데모의 브라우저 localStorage뿐입니다. 실제 문해 앱·문서·DB에는 연결하지 않습니다. ‘시연 처음으로’는 데모에 저장한 변경만 초기화합니다.

`demo-data.js`는 데이터 편집용 사본입니다. 배포 가능한 `index.html` 안에도 같은 데이터가 포함되어 있어 별도 파일 없이 실행됩니다.
