# 번역 자료 · 문서별 참고 패널 데모

독립 HTML/CSS/JavaScript 설계 시안이다. 운영 화면, SQLite, Electron IPC, AI 호출과 연결하지 않는다. 예시 코멘트는 검증된 역사적 판단이 아닌 상호작용 설명용 자료다. 원문은 기존 대화의 태상시 본문 일부를 세 예시 문서로 나누었다.

## 실행

```sh
python3 -m http.server 5175 --bind 127.0.0.1 --directory apps/desktop/src/renderer/prototypes/translation-materials
```

`http://localhost:5175/index.html`을 연다. 데스크톱 개발 서버가 실행 중이면 `/prototypes/translation-materials/index.html` 경로에서도 볼 수 있다. ES module을 사용하므로 `file://` 대신 로컬 서버로 연다.

## 눌러볼 흐름

1. **번역 자료**에서 배경·지침, 용어집, 코멘트를 전환한다. 검색과 적용 범위 필터가 작동한다.
2. **코멘트 재사용해 보기** → `太常` 코멘트 → **다른 문서에서도 참고**를 누른다.
3. 원래 코멘트를 보며 제목·참고 내용·조건을 편집한다. 한 문서 / 특정 권 / 프로젝트 전체 중 범위를 선택한다. 적용될 문서가 즉시 표시된다.
4. 저장한 자료에서 **문서에서 확인**을 누른다. 편집기의 참고 패널에서 프로젝트 → 상위 권 → 현재 문서 경로와 각 노드에 연결된 자료 수를 확인한다. 상위 프로젝트, 상위 권, 현재 문서, 다른 노드에서 직접 가져옴을 구분한다.
5. 자료의 체크를 끄면 **이 문서에서만 제외**한다. 원본 자료나 다른 문서에는 영향을 주지 않는다. 다시 체크하면 복원한다.
6. **다른 문서에서 가져오기**에서 배경·지침은 현재 문서에 계속 연결하고, 원문 코멘트는 이번 번역에서만 참고한다.
7. **전달 내용 보기**에서 적용 중인 자료, 조건, 근거 구절, 관련 용어를 확인한다. AI 전송은 실행하지 않는다.

자료·연결·문서별 제외는 `munhae:prototype:translation-materials:v1`이라는 전용 localStorage 키에 저장된다. ‘이번만 참고’는 메모리에서만 유지하며 새로고침 또는 **이번만 참고 비우기**로 해제된다. 실제 번역 실행이 없는 데모이므로 요청 완료에 따른 자동 해제는 구현하지 않는다.

## 설계 범위

- 자료 생성·수정, 코멘트 생성, 수동 재사용, 문서별 제외, 적용 범위·출처 조회
- 코멘트에서 재사용한 내용은 별도 자료로 저장하며 코멘트 원문은 유지
- 현재 자료 필터와 편집 대상의 구분, 원본 보기, 대화상자 취소·초점 복귀
- 키보드 조작과 작은 화면에서 세로 배치
- 데모 초기화는 전용 키만 변경

`/compact-comment`, 자동 관련도 판단, 실제 번역, 공유 서버, 운영 DB 마이그레이션은 이 데모의 범위에 포함하지 않는다. 이 시안의 localStorage 구조를 운영 DB 설계로 사용하지 않는다.

## 연결 노드와 상하 관계

- 자료 목록은 실제 연결 노드별로 묶고, 각 항목에 `관제 문헌 번역 › 예관 › 태상시 고찰` 같은 전체 경로를 표시한다. 연결 노드 이름으로도 검색할 수 있다.
- 상세 패널은 연결 노드를 강조한 트리에서 하위 문서의 상속과 개별 제외를 표시한다. 연결 범위 밖에서 직접 가져온 문서는 실제 경로와 함께 별도로 표시한다.
- 코멘트의 원본 문서와 재사용 자료의 연결 노드는 별개다. 원본 코멘트가 문서에 있어도 새 자료는 권이나 프로젝트에 연결할 수 있다.
- 적용 범위 폼에서도 같은 트리로 저장될 위치와 하위 문서를 미리 확인한다.
- 데모의 계층은 프로젝트 → 권 → 문서의 3단계다. 임의 깊이의 문서 트리나 노드 이동·삭제는 구현하지 않았다.
