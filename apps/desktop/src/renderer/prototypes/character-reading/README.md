# 구절 연구 시안

개발 서버: `/prototypes/character-reading/index.html`

첨부 화면의 문장과 풀이를 이용한 독립 시안이다. 실제 편집기나 프로젝트 DB는 변경하지 않는다. 프로덕션 빌드 진입점에는 포함하지 않았다.

## 화면과 동작

- 왼쪽: 원문·번역, 글자별 문맥 풀이, 풀이 순서, 문형, 선택 위치의 주석 편집.
- 오른쪽: 선택 글자의 실제 내장 사전 뜻풀이·출처와 Unihan 문자 속성.
- 기존 Electron preload 또는 Vite의 `/__munhae/api` 브리지를 통해 읽기 전용 사전 서비스를 호출한다. Electron 실행과 문해 로그인이 필요하며 연결 실패를 가짜 사전 결과로 대체하지 않는다.
- 사전 뜻을 선택하면 해당 위치의 문맥 풀이에 적용하고 출처·저작자·이용 조건을 보존한다. 이체자 조회는 원문을 수정하지 않는다.
- 주석은 전용 localStorage 키에 저장한다. 프로젝트에 저장하는 기능은 없으며 JSON 내려받기를 제공한다. 미반영 입력과 저장 실패 상태에는 종료 보호가 적용된다.

## 실제 편집기에 통합할 때

1. 기존 문장별 대조에서 선택한 문장을 이 보기의 입력으로 넘긴다. 사이드바와 상단 작업 단계는 유지하고 본문 안의 ‘구절 연구’ 보기로 제공한다.
2. 주석은 `documentId + sourceVersionId + codepointFrom + codepointTo`에 연결한다. 같은 글자가 반복돼도 위치별 풀이를 독립적으로 저장한다. 범위 끝은 포함하지 않으며 구두점도 원문 위치에 포함한다.
3. 기본 훈음, 선택한 사전 의미·출처, 직접 쓴 문맥 풀이, 풀이 순서를 구분해 저장한다. 한자어도 표현할 수 있도록 범위는 한 글자로 제한하지 않는다.
4. 원문 버전이 바뀌면 기존 주석의 대응을 검증하고 확인이 필요한 항목을 표시한다. 자형을 정규화하거나 위치를 묵시적으로 이동하지 않는다.
5. 기존 사전 서비스를 재사용하고 주석 저장은 프로젝트 저장 계층에 추가한다. 스키마 마이그레이션·버전 대응·저장 후 재열기 검증이 필요하다. 시안의 localStorage는 프로덕션 저장 방식이 아니다.

자원 설명·갑골문·금문 이미지·전문 자전의 출전별 용례는 현재 데이터에 없다. 이 화면에 표시하려면 별도 원자료 연결이 필요하다. 예시의 문맥 풀이와 문형은 제공된 화면을 바탕으로 입력한 것으로 자동 분석 결과가 아니다.

## 확인한 사항

- TypeScript 검사 통과.
- Orca에서 실제 내장 사전의 `綱` 뜻풀이, 糸 부수, 총 14획, 문자 정보 조회.
- 사전 뜻 선택 후 출처와 함께 저장되고 새로고침 후 유지됨.
- 두 `則`의 원문 위치 `[4,5)`, `[10,11)`에 서로 다른 풀이가 저장됨.
- 풀이 순서 전환 시 원문 문자열은 유지됨.
- 1311px 화면과 640px iframe 뷰포트에서 가로 넘침 없음.
