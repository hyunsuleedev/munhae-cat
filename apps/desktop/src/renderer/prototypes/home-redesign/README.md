# 프로젝트 홈 새 시안 (2026-09-28)

실행 중인 개발 서버에서 비교 페이지를 엽니다.

http://localhost:5173/prototypes/home-redesign/index.html

- **01-ledger.html — 작업 대장:** 홈 전체가 원문 표. 편별 묶음(접기), 검색, 상태 필터, 목차순/최근순, 키보드 이동(↑↓, Enter, `/`).
- **02-contents.html — 목록:** 번역하는 책의 目錄. 장마다 한 줄에 교정 표시(原·點·譯·覆·定), 열린 의문은 난외 메모, 끝줄의 표시가 곧 범례이자 필터.
- **02a-contents-detail.html — 목록 + 줄 끝 정보:** 02에 대장 정보를 더한 변형. 책의 쪽수 자리에 번역 버전·최근 작업 시각, 편 제목 옆에 확정 수, 목차 위 고정 도구줄(찾기·단계 필터·목차순/최근순), 편 접기.
- **02b-contents-switch.html — 목록 ↔ 대장:** 평소엔 02와 같은 목록. 도구줄에서 ‘대장’으로 바꾸면 같은 줄이 장·첫 구절·표점·번역·의문·최근 열로 펼쳐지고 최근순 정렬이 생김. 선택한 보기는 이 브라우저에 기억.
- **03-grid.html — 진행 격자:** 장 하나가 칸 하나. 칸을 고르면 오른쪽에 원문·번역·의문·기록, 화살표로 이동.
- **04-journal.html — 작업 일지:** 날짜별 작업 기록. 번역 수정 전후, 같은 때 가져온 원문 묶음, 오른쪽에 이어서·열린 의문·진행.
- **05-launcher.html — 첫 화면 최소:** 검색창과 최근 원문 6개, 상태 한 줄. 입력하면 원문·의문·명령을 찾음.

비교 페이지에서 원문 수(없음/3/40/93개)와 창 너비를 바꿀 수 있습니다. 각 시안은 `?scenario=empty|small|medium|large`로 따로 열 수도 있습니다.

## 구성

- `shared.js`: 예시 데이터(《論語》 學而~公冶長, 작업 기록, 불확실성, 문맥)와 실제 앱 크롬(사이드바·타이틀바·상태바). `mountShell()`이 `.content`를 돌려주고, `data-open-doc`가 붙은 요소는 문서 열기 알림을 띄웁니다.
- `shared.css`: 단계 색과 시안 표시. 앱의 `styles/tokens.css`, `styles/chrome.css` 위에 얹습니다.
- 실제 API·DB·저장·AI 호출을 쓰지 않습니다. 원문과 번역은 널리 알려진 장만 넣었고, 진행 상태·기록·의문은 화면 검토용 예시입니다.
