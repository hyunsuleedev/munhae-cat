# 프로젝트 홈 구성 비교

실행 중인 Munhae Vite 서버에서 다음 페이지를 엽니다.

http://localhost:5173/prototypes/home-directions/index.html

- **01-atlas.html — 문헌 지도:** 프로젝트 소개와 단계별 진행, 접고 펼치는 전체 목차, 다음 작업.
- **02-desk.html — 오늘의 책상:** 마지막 작업 이어하기, 검토함, 검색 가능한 작업 목록.
- **03-study.html — 연구 서재:** 프로젝트 설명과 공통 문맥, 진행 현황, 문헌 구성과 참고 자료.

비교 페이지에서 시안, 문서 수(0/1/12/80), 화면 너비를 전환할 수 있습니다. `따로 열기`는 각 시안을 독립 페이지로 엽니다. 개별 페이지도 `?scenario=empty|single|full|large`를 지원합니다.

## 데이터와 범위

`shared.js`의 메모리 내 예시 데이터로만 동작합니다. 태상시 구절 이외 문서명·목차·진행·활동·연구 메모는 화면 검토를 위한 구성 예시이며 실제 사료의 편제나 프로젝트 현황을 뜻하지 않습니다. 실제 프로젝트 API, DB, 인증, 저장, AI 호출을 사용하지 않습니다. 문서·자료·추가 버튼은 미리보기나 예시 안내를 엽니다.

파일은 기존 앱의 `home.html`과 독립되어 있습니다. 공통 스타일은 `base.css`, 시안 전환·화면 크기 조절은 `index.js`, 나머지 동작은 각 시안 JS에 있습니다. 외부 패키지나 이미지·폰트 다운로드가 필요 없습니다.

## 확인한 내용 — 2026-09-09

- 세 시안의 데스크톱·좁은 화면 렌더링과 문서 검색, 상태 필터, 미리보기.
- A/C: 0/1/12/80개 각 데이터에서 1440/1024/768/390px 가로 넘침 없음.
- B: 12개·빈 프로젝트 각각1440/390px, 80개1024px, 1개768px 가로 넘침 없음. 검색·검토필터·더보기·빈 상태 안내 확인.
- 문서 미리보기 Escape 닫기와 원래 버튼으로 포커스 복원.
- 비교 페이지의 세 시안 전환, 네 데이터 전환, 768px 너비 적용, 1440/1024/768/390px 레이아웃 확인.
- 비교 페이지는 실제 Orca 내장 브라우저에서도 표시 확인.
- JavaScript 파일 5개 구문 검사 통과. 상호작용 검사에서 uncaught JavaScript 오류 없음.

프로덕션 연동과 사용자 디자인 선택은 이 예시 구현에 포함되지 않습니다.
