# 문해 편집기 디자인 시안

`index.html`에서 세 가지 방향을 비교합니다. 모든 시안은 외부 라이브러리 없이 동작하는 HTML이며 실제 문해 API나 프로젝트 DB를 사용하지 않습니다.

- `01-folio.html`: 서책 — 따뜻한 병렬 지면과 문장별 대조 전환. 원문 8문장·번역 10문장을 명시적 대응 단위로 연결하며 1:다수 대응을 표시합니다. 두 보기의 번역을 함께 편집하고 문장별 검토, 재검토 표시, 메모, 미검토 필터를 사용할 수 있습니다. 번역과 검토 상태는 시안 전용 브라우저 저장소에 저장·복원됩니다.
- `02-synoptic.html`: 대조 연구실 — 문장별 원문·번역 대조와 검토 정보.
- `03-reading.html`: 주해 서재 — 번역문 중심 정독, 난외 주석, 집중 모드.

로컬 파일을 브라우저로 열거나 실행 중인 개발 서버에서 `/prototypes/editor-directions/index.html`로 접속할 수 있습니다. 저장 버튼은 데모 상태만 바꾸며 실제 문서에는 영향을 주지 않습니다. 서책의 저장 키는 `munhae.prototype.folio.comparison.v1`입니다. 문헌 본문과 메모는 디자인 검토용 예시입니다.
