# 연대기 사료 번역 지침

## 적용 범위
- 조선왕조실록, 승정원일기, 일성록처럼 날짜별 기사로 이루어진 관찬 연대기를 한국어로 번역할 때 쓴다.
- 번역 언어가 영어로 지정되어 있으면 이 지침의 한국어 문형 예시는 적용하지 않는다.

## 기본 원칙
- 원문 전체와 주어진 문맥을 먼저 읽은 뒤 번역 전문을 완성한다.
- 확정 표점이 있으면 그 표점을 따르고, 없으면 직접 구두를 떼어 해석한다. 사용자에게 표점이나 분절을 먼저 요구하지 않는다.
- 원문의 뜻, 논리 관계, 인명·지명·날짜, 한정·유보 표현을 모두 옮긴다. 어려운 대목을 요약하거나 말없이 빼지 않는다.
- 프로젝트의 용어, 한자 표기, 보충, 불확실성 원칙을 따른다. 판독이나 해석이 불확실한 곳을 확실한 것처럼 쓰지 않는다.

## 기사 구성
- 원문의 기사 구분(○ 등)마다 새 문단을 시작한다. 한 기사 안에서는 뜻의 흐름이 바뀔 때만 문단을 더 나눈다.
- 간지로 된 날짜는 한글 음으로 적는다(예: 정축). 한자 병기 여부는 프로젝트의 한자 표기 원칙을 따른다.
- 사관의 논평(史臣曰)은 본 기사와 구분되도록 새 문단에서 "사신은 논한다."로 시작한다.

## 문형
- 上은 "임금"으로 옮긴다. 원문이 上이라고만 했으면 묘호로 바꾸지 않는다.
- 啓曰은 "아뢰기를", 傳曰은 "전교하기를", 傳于○○曰은 "○○에게 전교하기를", 答曰은 "답하기를"로 옮긴다.
- 從之는 "그대로 따랐다", 不允은 "윤허하지 않았다"처럼 결정의 결과가 드러나게 옮긴다.
- 상소·차자·계사를 인용할 때는 인용의 시작과 끝이 분명하게 드러나게 하고, 인용 안의 臣은 "신"으로 옮긴다.

## 호칭과 표기
- 관직명과 관청명은 원래 이름을 한글로 적는다(예: 영의정, 도승지, 사헌부). 현대 행정 용어로 바꾸지 않는다.
- 인명은 원문에 나온 대로 적는다. 자·호·관직으로만 나온 사람을 다른 이름으로 바꾸지 않고, 누구인지 확실할 때만 보충 원칙에 따라 밝힌다.
- 재위년에 서기를 덧붙이는 것은 보충 원칙이 허용하고 환산이 확실할 때만 한다(예: 태종 3년(1403)).

## 제출 전 검토
- 원문과 대조해 빠진 기사, 빠진 인명·날짜, 덧붙인 설명이 없는지 확인한다.
- 같은 관직명·인명·문형을 문서 전체에서 같은 방식으로 옮겼는지 확인한다.
