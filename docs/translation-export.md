# 번역본 내보내기 (2026-09-28)

홈과 편집기의 **내보내기**(⌘E)는 하나의 창에서 두 종류의 출력을 고른다. 편집기에서 열면 범위가 현재 문서로 시작하고, 저장하지 않은 편집이 있으면 내보내지 않는다.

- **번역본**: 사람에게 건네는 완성 문서. Word(.docx), PDF, 텍스트(.txt), Markdown(.md).
- **확정 기록 보관**: 기존 확정 번역 내보내기(검증용 Markdown·JSON·CSV). 버전 식별자·해시·앵커를 보존하며 확정본만 포함한다.

번역본은 **구성**(번역문만 / 원문·번역 대역), **번역 버전**(현재 저장본 / 확정본만), **범위**(프로젝트 전체 / 현재 문서)를 고른다. 검토 상태·코멘트·버전 기록은 넣지 않는다. 검토자에게 보낼 대조표와 코멘트는 기존 **검토본 출력**을 쓴다.

## 구조

프로젝트 전체는 프로젝트 제목 아래 폴더를 제목 단계로, 원문 작업 단위를 그 아래 제목으로 둔다(마스터 폴더는 제외). 제목은 `제목(원제)` 형식이며, 바로 위 제목과 같으면 반복하지 않는다. 번역이 없는 문서는 건너뛴다.

## 대역

행은 번역 문단(줄바꿈 단위)이고, 원문 칸에는 그 문단의 문장들이 연결된 원문 범위를 넣는다. 원문은 번역에 사용한 표점, 없으면 같은 원문 버전의 확정 표점, 없으면 저장 원문으로 보여 준다. 연결은 표점 전 원문 좌표이므로 경계를 표점안으로 옮기며, 끝 문장부호는 앞 행에, 여는 괄호·따옴표와 줄바꿈은 다음 행에 붙인다.

모든 원문 글자는 순서대로 한 번씩만 나온다. 이를 위해 한 연결 묶음이 여러 줄에 걸치면 그 줄들을 한 행으로 묶고, 연결이 없는 문단은 앞 행에 합치며, 원문 순서가 뒤바뀌거나 겹치는 문단들은 한 행으로 합친다. 어느 연결에도 속하지 않은 원문은 앞 행에 남는다(첫 행 앞부분은 첫 행). 쓸 수 있는 연결이 없으면 문서 전체가 한 행이 된다.

## 형식별 구현

- **DOCX**: `packages/db-sqlite/src/translation-docx.ts`가 OOXML 부분을 직접 쓰고 `fflate`로 묶는다. 제목·제목 1–6·원문·대역 표를 스타일로 정의해 Word에서 한 번에 바꿀 수 있다. A4, 쪽 번호 바닥글. 한국어 문단은 어절 단위로 줄을 바꾸고 원문 스타일은 글자 단위로 바꾼다.
- **PDF**: 인쇄용 HTML(CSP로 모든 외부 요청 차단)을 임시 파일로 쓰고, 스크립트가 꺼진 숨은 창에서 `printToPDF`로 A4·쪽 번호·문서 개요와 함께 출력한다(`apps/desktop/src/main/print-pdf.ts`). 저장 위치를 고른 뒤에 인쇄하므로 취소는 비용이 없다.
- **TXT / Markdown**: 원문과 번역을 줄 단위로 적는다. Markdown은 대역 원문을 인용문으로 두고, 줄 첫머리의 목록·제목 표지와 인라인 강조 문자만 이스케이프한다.

HWPX, TMX, 용어집 TBX/CSV와 대역 DOCX 왕복 반영은 이후 단계다.
