# 한국고전종합DB 각주 용례 검색

편집기의 **각주 용례 찾기** 또는 오른쪽 **문맥 → 각주 용례 찾기**에서 검색한다. 코멘트 작성 중 **이 구절의 각주 용례 찾기**를 누르면 선택 구절이 검색어로 채워진다. 필요한 단어로 수정한 뒤 검색 버튼을 누른다. 구절 선택만으로 외부 검색을 실행하지 않는다.

## 검색과 검토

- **각주 대상 구절**: 각주가 붙은 전체 표현에서 부분 일치 검색한다. 기본값이다.
- **대상·설명 전체**: 대상 표현과 각주 설명을 함께 검색한다. 설명만 검색하는 기능은 아니다.
- 결과는 10개씩 조회하며 **이전/다음**으로 이동한다. **각주 대상 구절**, 보조 **표시 제목**, **각주 설명**, 서명·역자·간행처·간행년도를 구분하여 보여준다.
- **한국고전종합DB에서 보기**는 해당 문헌의 각주 위치로 연결한다. 외부 문헌의 각주이므로 현재 번역 구절과 문맥을 비교하여 판단한다. 대상 표현이 한국어 번역문일 수도 있어 한문 용어로 찾지 못하면 번역어로도 검색할 수 있다.

## 코멘트에 활용

코멘트 창에서 검색을 열면 **코멘트에 참고자료 넣기**가 표시된다. 선택한 각주의 대상 구절, 설명, 서지, 원본 링크를 기존 의견 뒤에 추가한다. 코멘트 저장은 별도로 누르며, 저장하기 전까지는 작성 중인 초안이다. 추가해도 선택 구절의 황금색 표시는 유지된다. 동일 자료의 중복 추가나 20,000자 초과는 알리고 내용을 잘라 저장하지 않는다.

독립 검색에서는 **출처와 함께 복사**로 같은 형식의 인용을 복사할 수 있다. 검색 결과 자체를 프로젝트에 자동 저장하지 않는다. 저장한 인용은 기존 코멘트 본문에 들어가므로 버전별 코멘트 이력과 선택한 코멘트를 이용한 재번역 요청에 함께 보존된다. 별도의 완성 번역 각주 번호나 자동 용어 판단을 생성하지 않는다.

## AI로 필요한 각주 추리기

검색어와 범위를 정한 뒤 **AI로 필요한 각주 추리기**를 누르면 여러 페이지의 각주를 수집하고 현재 문서의 문맥과 대조한다. 앱 설정의 AI와 모델을 사용한다. 검색 서비스에는 검색어만 전송하고, AI에는 현재 구절 주변의 원문·번역 문맥과 수집한 각주를 전달한다.

문장별 대조에서 원문 구절을 선택하고 **우클릭 → AI 각주 추천**을 눌러도 시작할 수 있다. 선택한 구절의 정확한 위치와 문맥을 사용하며, 원문·표점·번역에 저장하지 않은 변경이 있으면 먼저 저장해야 한다. 구절을 선택하거나 우클릭 메뉴를 여는 것만으로는 검색·AI 분석을 실행하지 않는다.

추천은 각주의 근거 구절, 참고할 이유, 번역에 반영할 제안, 적용 전 확인할 점으로 나뉜다. 다른 시대·인물·제도에 대한 설명을 현재 구절의 정답으로 취급하지 않으며, 자료가 부족하면 추천 없이 그 한계를 알린다. 추천의 각주와 인용은 실제 검색에서 받은 자료에 연결되고, AI가 만든 자료 ID나 원문에 없는 근거 인용은 결과로 표시하지 않는다.

한 번에 첫 5페이지, 최대 50개를 수집한다. 검색 전체 건수와 실제 분석 수, 길이 제한으로 일부만 전달한 자료 수를 표시한다. 추천은 이 검색 범위 안의 판단이며 DB 전체를 조사한 결과가 아니다. 원래 검색 목록과 추천 근거의 전체 각주는 직접 펼쳐 볼 수 있다.

추천·출처를 복사하거나 작성 중인 코멘트에 넣을 수 있다. 저장되는 문구에도 AI 제안과 원자료 인용을 구분한다. 코멘트 저장과 번역 반영은 기존 검토 동작을 따른다. 취소·창 닫기·검색 조건 변경 시 진행 중인 추천을 중지하고, 문서나 버전이 바뀌면 이전 결과를 새 문맥에 적용하지 않는다. 분석 자체는 프로젝트 번역·각주·채팅 기록을 자동으로 생성하지 않는다.

2026-09-08 실제 Codex 실행에서 `提調`의 대상 구절 검색 결과 128건 중 앞의 50건을 분석하여, 자료 식별자와 근거 인용 검증을 통과한 추천 2건을 확인했다. 나머지 78건은 분석하지 않았다. 《도곡집》의 「본감(本監)의 제조(提調)」는 감독·총괄 기능을 설명하는 **직접 관련 후보**, 《우서》의 「도제조(都提調)」는 봉상시의 감독 관직을 비교하는 **문맥 참고**로 구분되었다.

이 실행에서는 관상감의 겸직 방식·품계를 현재 문서의 태상시에 그대로 적용할 근거가 없고, 도제조 용례만으로 `公一人卿一人`의 관직 대응이나 구두를 확정할 수 없다는 주의점도 함께 반환되었다. 검토할 자료와 적용 한계가 출력된 사례이며 번역 해석의 확정을 뜻하지 않는다.

## 연결 및 검증

Electron main에서 `https://db.itkc.or.kr/openapi/search`로 `secId=JS_AA`, `keyword`, `start`, `rows=10`을 보낸다. 대상 구절 검색은 실측한 `주석_s:*검색어*` 문법을 사용하고 공백·검색 연산자를 리터럴로 이스케이프한다. 전체 검색은 검색 구절을 따옴표로 감싼다. `opFld=name`이나 축약 표제인 `주석명_s`를 대상 구절 필터로 쓰지 않는다. 이 필드 검색 문법은 공식 안내에 명시된 계약이 아니라 실제 응답으로 확인한 동작이다. 응답 구조가 바뀌면 잘못된 범위의 검색으로 자동 대체하지 않고 오류를 표시한다.

검색어는 최대 100 Unicode 코드포인트이다. 고정 HTTPS 호스트, 12초 타임아웃, 응답 2MiB 제한, XML DTD 차단, 요청 간격 500ms, 최대 2개 실행·대기 요청, 3분/32개 메모리 캐시를 적용한다. 사용자 원문 전문, 계정 정보나 인증 토큰을 검색 요청에 붙이지 않는다. 입력한 검색어와 검색 범위·페이지 정보만 전송한다.

2026-09-07 실제 조회에서 대상 검색 `태수` 294건, 전체 검색 `태수` 4,991건, 대상 검색 `가릉 태수`와 `100전(錢)`은 각각 1건을 확인했다. 결과 수는 DB 갱신에 따라 달라진다. 원본 링크의 `dataId`와 `jusokId`는 공식 페이지가 처리하는 문헌·각주 식별자이다.

공식 자료: [OpenAPI 안내](https://db.itkc.or.kr/etc/openAPI?type=page2), [각주 검색](https://db.itkc.or.kr/kakju/search).
