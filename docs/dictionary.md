# 한자·어휘 사전

2026-09-08 구현. 한국어 뜻풀이·훈음과 고문헌 용어를 편집기에서 조회한다.

## 사용

1. 편집기의 **용어·용례 → 한자·어휘 사전**을 연다. 번역 전에는 오른쪽 **문맥 → 한자·어휘 사전**에서도 열 수 있다. 문장별 대조의 원문·표점 대응 구절을 선택하고 우클릭한 뒤 **한자·어휘 사전**을 선택해도 된다.
2. 한자·한자어·한글 독음을 검색한다. 여러 글자를 입력하면 글자별 조회 버튼도 나온다. **부수·획수·이체자 보기**에서는 문자 속성과 관계별 이체자를 확인하고 관련 자형을 별도로 조회할 수 있다.
3. 뜻을 선택하면 출처·라이선스를 확인할 수 있다. **뜻·출처 복사**, **용어 등록에 가져오기**를 사용할 수 있다.
4. 원문 구절에서 열었다면 **코멘트에 뜻 넣기**로 해당 구절의 검토 초안을 만든다. 작성 중인 코멘트에서도 **한자·어휘 사전**으로 자료를 추가할 수 있다. 코멘트는 사용자가 저장해야 한다.
5. 저장한 코멘트를 선택해 기존 **코멘트로 재번역**을 실행하면 뜻풀이와 출처가 검토 의견으로 전달된다. 사전 조회 자체가 AI를 호출하지는 않는다.

사전에서 가져온 내용은 현재 문맥의 정답으로 확정하지 않는다. 용어 등록은 기존 항목을 자동으로 덮어쓰지 않으며, 미저장 용어 초안이 있으면 보존한다. 현재 문서·버전·선택 구절이 바뀐 뒤 오래된 사전 결과를 코멘트에 넣을 수 없다.

## 제공 자료

| 탭 | 이용 방식 | 범위 |
|---|---|---|
| 내장 사전 | 별도 키·인터넷 없이 조회 | libhangul 낱자 27,552자, 한국어 위키낱말사전 50,563표제어, Unihan 문자 속성 102,998자. 자료 사이 중복 있음 |
| 고문헌 용어 | KOSTMA 공식 위젯 검색 | 검색 요약과 상세 원문 링크. 전체 사전 DB를 복제하지 않음 |
| 우리말샘 | 무료 인증키 등록 후 조회 | 한자 원어 또는 한글 표제어의 뜻풀이 |
| 표준국어대사전 | 별도 무료 인증키 등록 후 조회 | 한자 원어 또는 한글 표제어의 검색 뜻풀이 |

내장 사전의 libhangul은 7,374자에 훈이 있고 나머지는 독음만 있다. 위키에는 현대 중국어 어휘도 한국어 풀이로 포함되어 있어 고전 전용 사전은 아니다. `提調`처럼 정확한 어휘가 없는 경우 낱자 보완이라는 안내를 표시한다. 원문 한자를 임의로 NFC/NFKC 정규화하거나 이체자로 바꾸지 않는다.

Unicode Unihan 17.0은 별도 **문자 속성** 항목으로 표시한다. 한글 독음·부수·총획·잔획과 의미상 이체자·특정 용법의 이체자·자형 이체자·번간체 대응을 구분한다. 복수 부수와 원자료의 간략형 표시도 유지한다. 영어 뜻풀이를 한국어 뜻처럼 넣지 않으며, 뜻풀이가 없는 문자 속성을 코멘트의 사전 뜻으로 가져올 수는 없다. 이체 관계를 확인해도 원문이나 검색어가 자동 치환되지는 않는다.

KOSTMA는 공식 위젯이 반환한 요약만 보여주며, 결과가 많아도 위젯에서 일부만 제공할 수 있다. 해당 자료는 앱에서 인용·복사·용어집 추가 대상으로 제공하지 않고 원문 사전 열람으로 연결한다.

네이버·Daum·단국대·한국어 위키낱말사전에는 검색어를 전달하는 외부 링크를 제공한다. 존한자는 사전 홈으로 연결한다. **사전 연결·출처**에서 공유마당 『자전석요』 원전도 열 수 있다. 비공개 옥편 API나 유료 공급사의 본문 수집은 사용하지 않는다.

## 무료 API 연결

사전 창의 **사전 연결·출처 → 연결할 사전 → 무료 키 발급 안내**에서 국립국어원의 신청 화면을 연다. 발급받은 인증키를 입력하고 저장한다. 키 저장은 입력 형식·저장 성공을 뜻하며 실제 유효성은 검색 응답으로 확인한다.

국립국어원 키는 Electron 메인에서 운영체제 `safeStorage`로 암호화해 기기의 `userData/dictionary-keys.enc`에 저장한다. 파일 권한은 0600이며, 상태 응답에는 등록 여부만 들어간다. 프로젝트 DB·내보내기·로그에 키를 넣지 않는다. 운영체제 보안 저장소를 쓸 수 없으면 평문으로 저장하지 않는다. **저장한 키 삭제**로 해당 사전의 키만 지운다.

검색은 사용자가 선택한 제공사에만 전송한다. 내장 사전에서 결과가 없다는 이유로 온라인 검색이나 AI 호출을 자동으로 시작하지 않는다. 온라인 연결 실패·잘못된 키·시간 초과·빈 결과를 구분해 표시한다.

## 데이터와 패키징

자료의 생성 방법·수록량·출처는 [오프라인 사전 데이터](offline-hanja-dictionary.md)를 참조한다. 위키 가공 데이터에는 CC-BY-SA-4.0, libhangul 자료에는 BSD-3-Clause, Unihan에는 Unicode License V3 조건이 적용된다. 국립국어원 검색은 뜻풀이와 출처만 사용하고 제3자 출전 예문·멀티미디어를 가져오지 않는다.

인용문에는 표제어·선택한 뜻·저작자·원문 링크·이용 조건을 함께 넣는다. 내장 데이터는 Electron main의 별도 청크에 포함되어 첫 사전 조회 때 지연 로드된다. `electron-builder.yml`의 `extraResources`가 `hanja-NOTICE.txt`를 설치 앱의 `licenses/`에 포함한다.

새 SQLite 스키마나 마이그레이션은 없다. 검토 코멘트·용어집의 기존 저장 구조를 사용한다.

## 검증

- 워크스페이스 TypeScript 검사와 데스크톱 프로덕션 빌드 통과. 최종 데스크톱 테스트 417개 통과, 별도 실행 조건이 필요한 live 테스트 5개 제외.
- 사전 입력·출처·빈 뜻·확장 한자·페이지, 비공개 키·암호화 저장·삭제, 제한된 외부 링크, 양쪽 IPC 통로 테스트.
- KOSTMA `太守`·`提調` 실제 API 응답.
- 별도 임시 프로필과 합성 문서로 실제 Electron main/preload/IPC/UI를 실행했다. 원문·표점 대응 구절 우클릭 검색, 용어 등록, 미저장 초안 보존, 구절 코멘트 작성·수정, 저장 후 앱 종료·재실행, 재번역 요청 미리보기의 뜻·출처·의견 포함을 확인했다.
- 확장 한자 `𪚥`를 선택하여 코멘트를 저장하고, 원문 코드포인트 범위 `[13,14)`를 IPC로 확인했다. 1280×800과 640×700 화면에서 사전 창이 화면 안에 표시됨을 확인했다.
- Unihan이 포함된 최종 빌드를 다시 실행하여 `𠮷`의 문자 코드·부수·획수와 뜻 미수록 처리를 확인했다. `謚`의 의미상 이체자 `諡`를 클릭하면 조회 대상만 바뀌고 원문은 그대로 남음을 IPC로 확인했다.
- 인증키 입력·암호화 저장·삭제는 테스트 키로 검증했다. 이 Electron 프로필은 인증 화면 통과에만 격리된 테스트 응답을 사용하며, 실제 계정 로그인 성공을 검증한 것은 아니다. 사전 IPC·저장·KOSTMA 통신은 실제 구현을 사용했다.
- 국립국어원은 발급된 키가 없는 상태로 구현했으므로 실제 키 검색은 미검증. 공식 명세를 반영한 JSON/XML·오류 응답 테스트를 수행했다.
