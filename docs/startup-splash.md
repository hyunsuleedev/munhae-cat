# 문해 시작 스플래시

앱을 처음 실행할 때 같은 Electron 창에서 `splash.html`을 먼저 엽니다. 그동안 앱 DB, 계정 서비스와 최근 프로젝트를 준비합니다. **앱 준비와 스플래시 애니메이션이 모두 끝난 뒤에만** 220ms 동안 사라지며 기존 시작 화면 또는 프로젝트 홈으로 이동하고, 기존 인증 게이트가 로그인 상태를 확인합니다. 편집기 이동이나 창 재활성화에는 스플래시를 다시 재생하지 않습니다.

3D 장면은 `apps/desktop/src/renderer/splash`에 포함되어 있습니다. 고서 표지, 종이 세 장, 실 제본, 17획의 `文解` 붓글씨와 먹 번짐은 승인된 `proto/splash-3d` 시안을 옮겼습니다. 고양이와 미리보기 조작 도구는 포함하지 않습니다. 붓글씨 구간은 6.25초이며, 전체 장면은 10.75초입니다. 앱 준비가 빨리 끝나도 장면을 끝까지 재생합니다. 장면이 먼저 끝나면 마지막 모습을 유지하면서 앱 준비를 기다립니다. 중간에 건너뛰는 버튼은 없으며, 진입 실패 시에만 재시도 버튼을 표시합니다.

Three.js는 스플래시에서만 동적으로 읽습니다. 글꼴·이미지·셰이더를 외부에서 받지 않으며 Arphic Public License와 AnimCJK 저작권 고지는 빌드의 `renderer/licenses/animcjk`에 포함됩니다. 동작 줄이기 또는 WebGL 실패 시 평면 표지를 사용하고 애니메이션은 완료로 처리하되 앱 준비는 기다립니다. 전환과 페이지 종료 시 프레임 루프, 메시·재질·텍스처와 WebGL 컨텍스트를 해제합니다.

`main/startup.ts`는 준비 완료 전 진입을 막고, 진입 요청을 한 번으로 합칩니다. IPC는 현재 문해 창의 `splash.html` 주 프레임에서만 허용되며 목적지는 main이 정합니다. 초기화 실패는 스플래시에서 안내합니다. 렌더러의 애니메이션 완료 요청 없이 일정 시간이 지났다는 이유로 강제 진입하지 않습니다. 창 닫기·앱 종료 시 대기를 취소합니다.

검증: 전체 타입 검사, 시작·인증 게이트·종료 보호 테스트, Electron 빌드 및 실제 main/preload/renderer 실행. 독립된 임시 프로필에서 정상 시작과 테스트용 지연을 준 시작을 확인하며, 사용자 계정과 프로젝트는 수정하지 않습니다. 스크린샷과 결과는 `output/playwright/munhae-native-*`에 저장됩니다.
