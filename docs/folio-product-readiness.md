# Folio 적용 및 제품 검증

2026-09-07 · Munhae Studio 0.1.0 · macOS Apple Silicon

1번 서책 디자인을 실제 편집기와 공통 화면에 적용했다. 원문·표점·번역·문맥·코멘트·이력은 기존 프로젝트 DB와 IPC를 사용한다. 시안의 예시 데이터나 브라우저 임시 저장을 제품 기능으로 대체하지 않았다.

## 적용한 기능

- 명조체 본문, 서책 색상, 간결한 제목 표시줄과 사이드바. 문장별 대조를 기본으로 하고 서책 보기·원문 전문·글자 크기·보조 패널을 전환한다.
- 문장과 전문은 같은 번역을 편집한다. 문장 저장 시 다른 문장의 줄바꿈과 연결을 보존한다. 변경·중복·새 문장은 추측해서 대응시키지 않고 재검토 대상으로 둔다.
- 원문을 직접 선택해 하나 이상의 구절을 번역 문장에 연결한다. 1:다·다:다 대응을 허용하고, 사람이 확인한 연결은 AI 재연결로 덮어쓰지 않는다. ‘대응 확인’은 번역 내용 전체의 학술적 검증 완료를 뜻하지 않는다.
- 작업 탭 이동 전에 수정 내용을 저장한다. 저장 실패 시 현재 입력을 유지하며, 저장·확정 중에는 추가 편집을 잠근다. 오래된 문서 응답은 적용하지 않는다.
- 구절 코멘트와 이전 번역 이력을 유지한다. 확정본은 읽기 전용이며 새 번역안으로 수정한다.
- 공통 지식의 미저장 항목 전환·페이지 이탈을 보호하고 구현되지 않은 용어 보관 버튼을 제거했다.
- 최신 WAL commit을 포함하는 백업 snapshot과 원자적 ZIP 교체를 사용한다. 복원 이름 충돌 시 `.munhae` 확장자를 보존한다.
- 종료 취소 시 DB·편집기·runtime을 유지한다. 일반 창 닫기에도 미저장 확인을 제공한다. 승인된 종료에서는 빈 페이지로 이동하여 새 홈 화면 요청을 시작하지 않는다.
- AI 준비 중 취소와 부모 종료 후 남는 보조 프로세스 정리를 수정했다.

## 검증 결과

최종 소스 타입 검사와 빌드가 통과했다. 각 패키지에 맞는 런타임에서 **397개 테스트 통과, 7개 명시적 제외**: DB·desktop 292개, 추가 경로 회귀 5개, domain 23개, project-format 24개, agent-runtime 53개. 제외된 검사는 실제 서비스 등 별도 환경을 요구한다. 처음 전체 테스트를 Electron에서 한꺼번에 실행했을 때 발생한 Node 전용 CLI fixture의 실행 환경·시간 제한 실패는 최종 패키지별 실행 결과와 구분했다.

| 실제 실행 범위 | 확인한 결과 |
|---|---|
| Electron 편집기 | 문장 수정 → 저장, CRLF·보조평면 한자 보존, 원문 연결 수정 → 저장, 코멘트 생성, 확정 → 새 번역안, 원문·표점·번역 교차 저장 |
| 문장 대응 | 수정하지 않은 사람 확인 연결 유지, 변경한 문장만 재검토, 원문 코드포인트 위치와 실제 선택 구절 일치 |
| 종료·재열기 | 취소 후 입력과 프로젝트 IPC 유지, 다시 저장 가능, 앱 종료·재실행 후 저장 내용과 연결 유지 |
| 백업·출력 | 실제 앱의 백업과 JSON 출력 생성. 별도 경로에 복원한 프로젝트에 확정 번역·사람 확인 연결 3개·코멘트 1개가 함께 보존됨 |
| 설치본 | 생성한 `.app`의 `app.asar` 화면, 실제 preload/IPC, Electron 37.10.3 및 포함된 SQLite로 편집·저장·복원·재열기 확인. 개발 서버를 사용하지 않음 |
| DB 무결성 | 설치본에 포함된 native 모듈로 `quick_check=ok`, `foreign_key_check=[]` 확인 |
| 화면 | Orca 1311px 및 실제 Electron 960px에서 보기 전환과 넘침 확인. 지식 화면의 취소·미저장 보호 확인 |

모든 쓰기 검증은 별도 임시 프로젝트와 격리 프로필에서 수행했다. 사용자 문서 내용은 수정하지 않았다. 종료 검증의 native 대화상자 응답은 격리된 main process에서 결정적으로 지정했고, 실제 renderer의 beforeunload와 서비스 종료 경로를 실행했다.

## 실행 파일과 배포 경계

로컬 실행 파일: `apps/desktop/release/mac-arm64/Munhae Studio.app`. 기존 고양이 아이콘을 사용한다. Electron 의존성과 패키징 버전을 37.10.3으로 일치시켰다.

이 결과는 **로컬에서 실제 기능을 검증한 배포 후보**다. 다음 작업은 완료하지 않았다.

- Developer ID 서명, Apple 공증·Gatekeeper 승인, 깨끗한 다른 Mac에서의 설치 검증
- 실제 모델 요청·결과 제출·취소를 포함하는 provider별 실서비스 검증
- 공개 배포·자동 업데이트 및 Windows/Linux 설치 검증

현재 출력 형식은 확정본 Markdown·JSON·CSV다. 주석 포함 Word/PDF 출판물이나 결제·라이선스 판매 시스템을 구현했다는 의미는 아니다.
