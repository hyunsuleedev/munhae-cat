# 채팅 UI (2026-09-18)

문서/프로젝트와 문맥 노트 채팅은 chat-ui.ts와 chat-ui.css의 메시지·Markdown·초안·스크롤 처리를 공유한다.

- Markdown: 인용, 제목, 목록, 표, 코드, 강조, 웹 출처 링크. 원문 문자는 정규화하지 않는다. 원시 HTML은 텍스트로 표시하고 원격 이미지는 불러오지 않는다.
- 웹 출처 클릭은 app.openChatSource로 외부 브라우저에 전달한다. 기존 사전/도움말 주소 허용 목록을 변경하지 않는다.
- 질문은 말풍선, 답변은 본문. 복사와 질문 재사용 액션을 제공하며 모델 정보는 보조 정보로 둔다.
- 범위·모델을 간결하게 표시하고 전송 자료 설명은 접이식으로 둔다. 입력 높이는 내용에 따라 증가한다.
- 실행 중에도 후속 질문 초안을 작성할 수 있다. 전송은 현재 실행이 끝난 뒤 가능하며 자동 큐잉하지 않는다.
- 초안은 대화 범위별 localStorage에 보관한다. 시작 실패 시 이미 작성한 다음 질문을 덮어쓰지 않는다. Cmd/Ctrl+Enter는 IME 조합 중 실행하지 않는다.
- 위를 읽으면 자동 따라가기를 해제하고 최신 답변 버튼을 제공한다. 실패 시 질문을 다시 실행할 수 있다.

검증: Markdown/링크/IME/초안 및 기존 관련 테스트, 타입 검사, 빌드. 격리된 Electron + 테스트 CLI 이벤트 재생으로 실제 Markdown 표시·복사·후속 초안 보존을 확인한다. 공급자 응답 품질 검증과 구분한다.

최종 확인: 관련 desktop 테스트 26개와 타입 검사 통과. Electron 재생 검증에서 완료 후 scrollTop=0 유지, 최신 답변 버튼, 실행 중 입력 가능, 대화 범위별 초안 복원, 새로고침 후 초안 복원, Markdown 표/출처, 복사 상태 표시는 모의 클립보드로 확인했다(당시 시스템 클립보드는 미검증). 실제 앱은 테스트 CLI 없이 새 빌드로 재실행했다.

복사 오류 수정: Electron은 웹 권한을 차단하므로 navigator.clipboard 대신 app.copyText IPC를 통해 main의 clipboard.writeText를 사용한다. 브라우저 실행은 해당 브라우저의 navigator.clipboard를 사용한다. 재실행한 실제 Electron에서 답변 복사 버튼의 “복사됨” 표시와 macOS pbpaste 결과의 SHA-256이 저장된 메시지 원문과 일치함을 확인했다. 타입 검사, 채팅 UI 테스트 4개, 빌드 통과.
