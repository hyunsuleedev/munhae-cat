# 전통 알림음 후보 조사

확인일: 2026-09-10. 추천 가야금 G4를 취득하여 0.8초 알림음으로 편집하고 앱에 적용했다. 채팅 성공은 한 음, 번역 저장·원문 연결·표점 성공은 두 음. 설정에서 독립적인 on/off, 음량, 미리듣기를 제공한다. 아래 비교 후보와 설계 조사 내용을 보존한다.

## 추천: 국립국악원 가야금 단음

- [가야금 단음(긴음 + 짧은음) G4 / Gayageum_SingleNote2_G4](https://www.kogl.or.kr/recommend/recommendDivView.do?division=audio&recommendIdx=51591)
- 국립국악원, 2022, 공공누리 제1유형. 상세 페이지에 영리 이용, 2차적 변경, 온/오프라인 이용 허용이 명시되어 있다. 출처를 표시해야 한다.
- 짧은 발음을 잘라 AI 채팅 답변 완료에 한 번, 번역 단계 완료에 두 번 사용하는 구성을 제안한다. 길이 0.4~1초는 편집 목표이며 원본 길이 확인 결과가 아니다.
- 공공누리 다운로드는 로그인/개인정보 이용 동의를 요구할 수 있다. 실제 취득 시 작곡/실연자 표시 등 파일별 출처 정보를 보관한다.

- [국악 효과음 #206](https://gongu.copyright.or.kr/gongu/wrt/wrt/view.do?menuNo=200020&wrtSn=13387196): 주식회사 아이티앤, CC BY. 설명은 '몽환적으로 흩날리는'. 빈번한 채팅 알림보다는 여운 있는 완료 알림의 비교 후보.

## 적용 설계 제안

- 배경음악과 별도의 알림음 on/off 및 음량, 미리듣기 제공.
- 채팅은 스트리밍 조각마다가 아니라 답변이 성공적으로 끝난 시점에 1회.
- 번역은 번역 생성/원문 연결 등 실제 단계 성공 시 1회. 실패·취소를 성공 소리로 알리지 않는다.
- 기존 editor.ts의 api.ai.onEvent, receiveAiRun, receiveAuxiliaryRun과 폴링 경로를 함께 검토한다. 동일 run/단계 완료를 중복 통지하지 않도록 식별자를 기록하고, 화면 재진입 시 과거 완료 기록으로 울리지 않게 한다.
- 다른 화면에서도 알림이 필요하면 공통 shell 또는 main에서 이벤트를 관리한다. 배경음악과 알림음의 음량은 독립적으로 유지한다.
- 확정 음원 취득 시 라이선스 원문, 출처 URL, 저작자, 변경 내역을 함께 배포한다.
