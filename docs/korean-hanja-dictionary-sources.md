# 한국어 풀이 한자사전: 데이터 공급·API 재조사

조사일: 2026-09-08. 한국어로 한자의 여러 뜻을 설명하는 옥편과 한국 고문헌 어휘 사전으로 범위를 좁혔다. 중국어·영어 풀이 사전은 이번 추천에서 제외했다. 조회와 공개 샘플 확인만 했으며 업체 연락·가입·구매·앱 구현은 하지 않았다.

추가 실검증: [한국어 옥편·고문헌 사전 API 상세 조사](korean-hanja-api-audit.md). 네이버 내부 JSON과 공식 API의 차이, 동일 네 표본 비교, 단국대의 웹 수록량, 현재 KOSTMA 외부 위젯, 국립국어원 다운로드 경로를 보완했다.

## 핵심 결과

**e-hanja 공급사의 공식 회사 사이트에서 실제 한자 DB 공급·라이선스 사업을 확인했다.** 앞선 조사에서 확인한 개인용 앱의 8,913자만이 공급 가능한 데이터 규모는 아니었다. 무료 자료 중에서는 여러 한국어 자의를 갖추고 재배포 조건까지 명확한 새 완성형 옥편 DB를 확보하지 못했다.

## 1. e-hanja: 실제 DB 공급 사업 확인

출처: [(주)오픈마인드인포테인먼트 공식 사이트](http://www.openmindinfo.kr/). HTTPS 연결은 실패했지만 HTTP는 실제 200으로 열렸고 본문을 확인했다.

- 사업 설명: 한자사전 DB 개발, 여러 업체와 DB 제휴, 교육 콘텐츠 개발·공급.
- 상품 설명: **표제자 71,280자와 한자 어휘 약 18만 개**, 이체자·유의자·상대자·고사성어 및 여러 검색 기능.
- 연혁: e-hanja Full Pack DB 개발·웹서비스, 네이버·다음·네이트·디오텍·윤디자인과의 e-hanja Database 라이선스 계약을 명시.
- 문의 안내: **한자 DB 공급 및 기타 개발 제휴 문의**를 받는다고 명시.
- 개인용 앱의 **8,913자·약 7.4만 어휘**는 별도 제품 설명이다. 전체 공급 DB와 혼동하면 안 된다.

이 페이지는 마지막 연혁이 2020년이며 Unicode 10.0 기준을 기재한다. 따라서 71,280/18만은 **확인한 공급사 페이지의 상품 설명 수치**이고, 현재 납품 판본의 검증된 수록량이나 모든 표제자의 상세 풀이 충실도를 뜻하지 않는다.

확인하지 못한 사항: 공개 API 명세, 최신 납품 판본, 실제 전체 DB 파일, 파일 형식, 가격, 최소 계약 규모, 오프라인 앱 탑재·재배포·외부 AI 입력의 허용 범위. 이는 업체 계약으로 확인해야 한다.

한국어 풀이의 실물도 확인했다. [공식 `目` 검색](http://www.e-hanja.kr/e-hanja/dic/jajun/jajun_search.asp?keyword=%E7%9B%AE)에서 **15개 자의**와 이체자·유의자·자원이 반환됐다. 시각 기관뿐 아니라 견해·안목, 요점, 표제, 목록, 우두머리 및 주시하는 행위 등의 한국어 설명이 있다. 공개 검색 페이지에 사용된 요청으로 확인했으며, 이 내부 요청을 외부 개발자용 공식 API라고 간주하지 않는다.

공식 문의처는 사이트 CONTACT의 `webmaster@openmindinfo.kr`, `031-757-6504`다. 개인용 앱은 [(주)오픈마인드지앤에이 명의](https://play.google.com/store/apps/details?hl=ko&id=kr.openmindgna.ehanjab)로 제공된다. 계약할 법인과 현재 권리 보유자를 문의 시 확인한다. 연락하지 않았다.

문해의 목적에는 한국어 다의 풀이·관련 어휘·이체 관계를 함께 공급받는 범위를 먼저 확인하는 것이 적절하다. 사전 데이터의 화면 표시와 사용자가 선택한 뜻을 AI 재번역 근거로 보내는 이용을 함께 설명해야 한다.

[다올소프트](https://www.daolsoft.com/business/content-licensing)는 공식 콘텐츠 라이선싱 사업을 확인했지만 특정 한국어 옥편의 공급 조건은 확인하지 못했다. [SELVAS DioDict](https://www.selvasai.com/diodict)는 현재 사전 앱·오프라인 사용 설명까지 확인했으며 외부 앱용 한국어 옥편 DB 공급 상품은 확인하지 못했다. 공급 내용이 더 구체적인 e-hanja를 우선한다.

존한자사전의 [실제 목록](https://zonmal.cafe24.com/hanja_tot.asp?tt=10)에서 `格`은 도달·바로잡음·궁구·대적 등의 한국어 의미를 나열한다. 원문 페이지의 저작권 고지와 별개로 앱 이용 계약은 확인되지 않았다.

단국대의 현재 통합 검색 대상은 『한국한자어사전』·『이두사전』·『한국한자자전』이다. [『한한대사전』 통합 DB 사업 설명](https://www.dankook.ac.kr/web/-oriental/-49)이 있다고 해서 『한한대사전』 전체가 현재 다운로드된다고 표현하면 안 된다.

### KOSTMA 실제 요청과 반환 범위

```text
https://kostma.aks.ac.kr/api/API_dicWordListY.aspx?xsl=no&clsCode=A
https://kostma.aks.ac.kr/api/API_dicViewY.aspx?searchid=DIC_B1_000762
```

목록 API에서 가/枷, 가각고/架閣庫 등을 확인했다. 내용보기 API의 관압사 항목은 한글항목명, 한자항목명(管押使), 출처, 웹페이지 URL을 반환했으며 **한국어 풀이 본문은 반환하지 않았다**. 로그인·키 없이 응답했지만 전체 수집·상업 재배포 조건까지 확인된 것은 아니다. [공식 위젯 안내](https://kostma.aks.ac.kr/OpenUI/guide_dicOpenUI.html)도 검색·연결 기능의 근거다.

국립국어원 API는 한자어를 한글 독음으로 먼저 변환할 필요 없이 원어 대상으로 검색할 수 있다. 우리말샘·표준국어대사전은 `advanced=y&target=2`, 한국어기초사전은 `advanced=y&target=4&lang=2`다. 유효 키로 정상 응답을 검증하지는 않았다.

## 3. 새로 발견했지만 상세 옥편으로 채택하기 어려운 자료

### Nexum 유료 ‘한자사전’

[공식 사이트](https://nexum.kr/)는 파일 다운로드 99만원과 구독 상품을 안내한다. [공식 샘플](https://nexum.kr/exam/sample_download.jsp)의 [sample_hanja.xlsx](https://nexum.kr/exam/sample_hanja.xlsx)를 직접 받았다.

- HTTP 200, 8,272바이트, 헤더 포함 101행.
- 필드는 **hangul / hanja 두 개뿐**이다.
- 예: 흠탄↔欽歎, 흡반↔吸盤, 가가호호↔家家戶戶.
- 샘플에는 뜻풀이가 없다. 따라서 공개 샘플 기준으로 한글 어휘와 한자 표기의 대응 데이터이며, 문해가 찾는 상세 옥편으로 추천하지 않는다.
- 홈페이지 가격표만으로 계약 조건이나 현재 견적을 확정하지 않았다. 구매하지 않았다.

### 옛 ‘한자딕’ DB

[해피CGI의 한자 사전 DB](https://happycgi.com/program/detail.php?number=13322)는 짧은 한국어 훈·획수와 영어 의미를 담는 과거 자료다. [2016년 오픈오피스 당사자 논의](https://groups.google.com/g/aookr/c/gcbN0wrsq9Q)에도 해당 자료의 출처와 라이선스가 불명확해 반영에 문제가 있다는 지적이 있다. 다운로드 게시물만으로 재배포를 허용하는 자료로 분류하지 않는다.

원개발자 Dan Bravender의 [현재 사이트](https://koreanhanja.app/)와 [개발자 설명](https://blog.koreanverb.app/2021/12/korean-hanja-vocabulary-tool-ios-app.html)을 추적했으나 재사용 가능한 전체 DB·공개 API 조건은 확보하지 못했다. 한국어 훈음과 영어 어휘 설명의 조합이라 이번 상세 한국어 풀이 조건에도 부족하다.

### 무료 한국어 옥편 원문 PDF

한국저작권위원회 공유마당의 [(증보)자전석요](https://gongu.copyright.or.kr/gongu/wrt/wrt/view.do?menuNo=200019&wrtSn=9082919)는 지석영 저작, 국회도서관 출처, 1918년판이며 **‘자유이용 만료’**로 표시된다. 공식 다운로드가 실제 PDF를 반환하는 것까지 확인했다.

- 원문 파일명: `(증보)자전석요.pdf`.
- 다운로드 메타데이터 및 PDF 헤더: 496,600,399바이트, 468쪽.
- 파일 앞부분만 받아 PDF 형식을 검증했다. 약 497MB 전체 파일을 내려받거나 전체 내용을 검사하지 않았다.
- 한글로 음과 뜻을 설명하는 옛 옥편 원전이다. 즉시 사용할 JSON/CSV DB가 아니며, 텍스트 추출 가능성·전산화·현대 한국어 정리·교정 작업의 규모를 별도로 평가해야 한다.

국가 기관이 제공하는 옥편 원전이라는 점에서 자체 사전 구축의 참고 후보는 되지만, 지금 앱에 넣을 현대 한국어 상세 옥편의 대체재로 권하지 않는다.

## 추천

한국어 상세 옥편을 앱에 넣는 목표라면 **e-hanja 정식 DB 공급 범위 확인을 우선**한다. 무료로 시작하는 범위는 libhangul 기본 훈음과 한국어 위키낱말사전의 검증된 항목이며, 한국 고문헌 용어는 단국대·KOSTMA 연결을 보완 수단으로 둔다.

이번 조사에서 **상세 한국어 옥편 전체를 제공하며 즉시 발급받을 수 있는 무료/유료 공개 REST API는 확인하지 못했다.** 이는 한국어 사전 데이터 자체가 없다는 뜻이 아니다. 기업용 DB 라이선스 공급은 실제 존재하며, 파일·SDK·API 중 어떤 형태로 제공되는지는 계약 문의로 구체화해야 한다.
