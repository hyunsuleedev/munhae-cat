# 번역 자료

프로젝트의 번역 자료는 사이드바의 독립된 세 화면에서 관리한다. `knowledge.html`(문맥)은 배경·지침 자료를, `glossary.html`(용어집)은 공통 용어를, `comments.html`(코멘트)은 구절별 코멘트를 모은다. 각 폴더·문서를 펼치면 나타나는 `문맥` 항목은 `context.html?node=...`에서 해당 노드의 문맥을 직접 작성하고 상속 내용을 확인한다. 두 문맥 화면은 같은 자료를 사용하며, 프로젝트 문맥 화면이 노드별 문맥 편집을 대체하지 않는다.

## 위치와 적용 범위

자료의 연결 위치는 실제 문서 노드다. `프로젝트 → 권 → 문서`처럼 고정된 단계가 아니라 `parentId`를 따라 전체 경로를 표시한다. 상속 여부를 끄면 연결한 노드에서만 사용하고, 켜면 그 하위 문서에서도 참고한다. 기존 문맥 자료는 이전과 같이 하위 문서에 이어진다.

문서의 참고 자료 패널은 현재 노드의 자료, 상위에서 이어받은 자료, 다른 노드에서 직접 가져온 자료를 구분한다. 문서에서 제외해도 원본 자료와 다른 문서의 사용 여부는 바뀌지 않는다. 다른 갈래의 자료를 직접 가져와도 원래 연결 노드가 이동하지 않는다. 문서 설명도 출처를 보존한 참고 자료로 취급한다.

## 코멘트의 재사용

코멘트를 선택하고 참고할 내용·적용 조건·연결 노드를 정하면 별도 자료가 만들어진다. 원래 코멘트를 수정하거나 삭제하지 않는다. 출처에는 선택 구절, 원문 또는 번역문 버전, 코멘트 본문과 당시 수정 버전을 보존한다. 자료의 적용 노드와 코멘트가 작성된 원래 문서는 서로 다른 정보다.

다른 문서의 코멘트를 이번 번역에만 참고할 수도 있다. 이 선택은 현재 번역에 대한 수정 요청과 별도로 전달한다. AI에 전달하기 전의 미리보기와 실제 요청은 같은 자료 선택을 사용한다. 코멘트 정리나 관련도 판단을 자동으로 수행하지 않는다.

## 저장

자료는 기존 프로젝트 SQLite의 `context_items`를 확장해 저장한다. 문서별 포함·제외 설정과 원본 코멘트 출처도 프로젝트 안에 저장한다. 화면의 예시용 localStorage 구조는 사용하지 않는다. 저장 충돌은 수정 버전으로 검사하며, 충돌 시 다른 창의 변경을 덮어쓰지 않는다.

스키마 7 업그레이드는 기존 자료를 보존한다. 실제 프로젝트의 열기·마이그레이션 전에는 백업을 만들고, 무결성 검사와 문서 재열기 후 저장 상태를 확인한다.
